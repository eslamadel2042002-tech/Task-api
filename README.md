# .NET Backend Tasks

This repository contains a collection of backend development tasks and projects built using **C#** and **.NET**, as part of the **Backend Development course**.

## 📚 Course Scope

The course introduces and deepens backend development skills using the Microsoft .NET ecosystem. Covered topics (so far) include:

- ✅ Databases (SQL Server)
- 👉 C# Programming Fundamentals
- 🧩 Ongoing: More .NET backend topics coming soon...

## 📁 Repository Structure

```
/Tasks
│
├── task1/      # First task
├── task2/      # Second task
├── taskN/      # Additional tasks to be added
└── README.md
```

Each folder represents a separate task, including:
- A `.csproj` file
- Source code
- Solution files (`.sln`)
- Build outputs (`bin/`, `obj/`)

## 🛠️ Technologies & Tools

- C#
- .NET SDKs
- Visual Studio
- SQL Server
- Git & GitHub

## 🧪 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alkahlawy/tasks.git
   ```

2. **Open any task folder** in Visual Studio.

3. **Build & run the project** using the IDE or terminal.

> Ensure that the correct version of the .NET SDK is installed on your machine.
